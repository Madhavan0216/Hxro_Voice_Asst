# Security Policy

## Supported versions

Only the latest version on the `main` branch is currently supported.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Contact [Madhavan0216](https://github.com/Madhavan0216) privately through GitHub with:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigation

Never include API keys, contact data, or other secrets in a report.
